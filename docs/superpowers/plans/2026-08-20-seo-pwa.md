# SEO + PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship crawler files, one site-wide Open Graph card, and an
installable app-shell PWA so `/`, `/compare`, `/explore`, and `/saved`
work offline after the first successful visit.

**Architecture:** Head tags live in `src/Document.tsx`. Copy and the
production origin live in `src/lib/site.ts`. Static files in `public/`
are copied to `dist/client` and win over the Netlify SPA fallback.
`vite-plugin-pwa` Workbox `generateSW` precaches that tree;
`src/pwa.ts` registers the worker. Vitest never loads the plugin;
`virtual:pwa-register` aliases to a no-op stub.

**Tech Stack:** Solid 2.0, Vite 8, `vite-plugin-pwa` 1.3.0+ (devDependency
only), Workbox via the plugin, Vitest, Netlify static (`dist/client`).

## Global Constraints

- Solid 2.0 APIs only. No `onMount`.
- `v` stays `1`. No search-schema or `src/lib/gear/` changes.
- Package manager pnpm. No `package-lock.json`. No Corepack.
- New **devDependency** only: `vite-plugin-pwa` (1.3.0 or later on the
  1.x line whose peer range includes Vite 8). Do not add Workbox or
  `@vite-pwa/assets-generator` as direct dependencies. Do not bump
  `solid-js` or TanStack.
- Head tags live in `src/Document.tsx`. There is no `index.html`.
- Netlify publish dir remains `dist/client`.
- Origin: `https://fixie-gears.netlify.app` (no trailing slash).
- Manifest `id`: `https://fixie-gears.netlify.app/` (trailing slash).
- Title / name / short_name: `Fixie Gears`
- Description: `Street-fixie ratio calculator. Gear inches, development, skid patches, and chain links — every setup is a URL.`
- `og:image:alt`: `Fixie Gears — street-fixie ratio calculator`
- Accent `#FF5A1F`, paper `#FAFAF8`, ink `#111214`
- Last task deletes `docs/superpowers/` so `main` keeps four handbook
  pages.
- After editing: `pnpm test`, `pnpm typecheck`, and `pnpm check` must
  pass. `pnpm build` must emit `dist/client`. Existing tests must not
  drop.

import { readFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";
import { describe, expect, it } from "vitest";

const publicDir = join(
  dirname(fileURLToPath(import.meta.url)),
  "../../public",
);

const PNG_SIG = Buffer.from([137, 80, 78, 71, 13, 10, 26, 10]);

function pngSize(name: string): { width: number; height: number } {
  const buf = readFileSync(join(publicDir, name));
  expect(buf.subarray(0, 8).equals(PNG_SIG)).toBe(true);
  return {
    width: buf.readUInt32BE(16),
    height: buf.readUInt32BE(20),
  };
}

describe("public icons", () => {

```bash
CONVERT=$(command -v magick || command -v convert)
BOLD=/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf
SANS=/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf

"$CONVERT" -background none public/favicon.svg \
  -resize 180x180 public/apple-touch-icon.png
"$CONVERT" -background none public/favicon.svg \
  -resize 192x192 public/pwa-192.png
"$CONVERT" -background none public/favicon.svg \
  -resize 512x512 public/pwa-512.png

"$CONVERT" -size 192x192 xc:'#FF5A1F' \
  \( public/favicon.svg -background none -resize 154x154 \) \
  -gravity center -composite public/pwa-192-maskable.png
"$CONVERT" -size 512x512 xc:'#FF5A1F' \
  \( public/favicon.svg -background none -resize 410x410 \) \
  -gravity center -composite public/pwa-512-maskable.png

"$CONVERT" public/pwa-192.png \
  -define icon:auto-resize=16,32,48 public/favicon.ico

"$CONVERT" -size 1200x630 xc:'#FAFAF8' \
  -fill '#FF5A1F' -font "$BOLD" -pointsize 92 \
  -gravity Northwest -annotate +80+160 'Fixie Gears' \
  -fill '#111214' -font "$SANS" -pointsize 36 \
  -annotate +80+280 'Street-fixie ratio calculator.' \
  -fill none -stroke '#FF5A1F' -strokewidth 16 \
  -draw 'translate 980,315 circle 0,0 0,92' \
  -fill '#FF5A1F' -stroke none \
  -draw 'translate 980,315 circle 0,0 0,28' \
  public/og.png
```

Maskable mark is ~80% of the canvas (154/192, 410/512). OG is paper
field, accent wordmark, ink first sentence, chainring on the right.

If `draw 'translate ...'` fails on older ImageMagick, use:

`-draw 'circle 980,315 980,223'` and `-draw 'circle 980,315 980,287'`.

Do not add a `scripts/` generator to the repo. Do not run this at
